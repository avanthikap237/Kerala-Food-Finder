# Taste of Kerala — Kerala Food Finder

A responsive front-end website for discovering a selection of Kerala dishes.

## Features
- Browse Kerala dishes with short descriptions
- Search by dish name, category or region
- Filter vegetarian and non-vegetarian dishes
- Filter by region: Malabar, Central Kerala, Travancore and Across Kerala
- Quick category filters for biryani, breakfast, seafood and snacks
- View additional dish details in a dialog
- Save favourite dishes during the current browser session

## Built with
- HTML
- CSS
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Notes
This is a front-end learning project with sample dish descriptions. It does not provide live restaurant listings, ordering, maps or nutrition information. Favourite dishes are saved only while the page remains open.
